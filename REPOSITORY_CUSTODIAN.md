# Repository Custodian Notice

This fork of the `schedule` repository is monitored and maintained by a **Repository Custodian**.

## What is a Repository Custodian?

A Repository Custodian is an automated system that oversees specific aspects of repository maintenance, focusing on:
- Basic scheduling functionality
- Cancellation capabilities

## Scope of Monitoring

The Repository Custodian for this repository focuses on:
- Ensuring basic job scheduling operations work correctly
- Monitoring cancellation features for scheduled jobs
- Maintaining the core scheduling functionality as outlined in the project's supported features

## Limitations

Please note that the Repository Custodian's monitoring is limited to the specified features (basic scheduling and cancellation). Other aspects of the repository may not be actively monitored by this automated system.

## Human Oversight

While automated monitoring is in place, human maintainers and contributors still play a vital role in the project's overall health and direction.
